# Failure Modes
F-001 Métrica macro incorreta → decisão errada → canonical metric + provenance.
F-002 Unidade errada milhões/bilhões → erro material → unit contract + tests.
F-003 Cenário tratado como observado → desinformação → output classification.
F-004 INSS falso positivo tratado como fraude → dano social/jurídico → review-only.
F-005 Agente escreve em dado oficial → corrupção → no write tool.
F-006 Schema drift silencioso → indicador quebrado → quarantine.
F-007 Fonte desatualizada → análise enganosa → freshness gate.
F-008 Modelo pior substitui champion → degradação → backtest gate.
F-009 PII entra no trace → privacy incident → pre-trace redaction.
F-010 Reviewer corrige próprio finding → conflito de papel → read-only reviewer.
